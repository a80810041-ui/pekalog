🧪 PEKALOG収集

iPhoneで一度だけ設定

  1. Safariでこのページをブックマークする
  2. ブックマークを編集して名前を PEKALOG収集 にする
  3. URL欄を全部消して、下のコードに置き換える
  4. P's CUBEでどれか1台の詳細画面を開いて、ブックマーク「PEKALOG収集」をタップ
もしコピー時に javascript: が消えたら、URL欄の先頭だけ手入力で javascript: と入れてから残りを貼ってね。

毎日の使い方

台詳細 → PEKALOG収集 → JSON保存 → LABの「収集JSONを読み込む」。22台をまとめて取るので、1台ずつスクショする必要はなし。
