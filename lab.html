👻 「その後どうなった？」

PEKALOGの保存実戦を同じブラウザから自動読込。LABに10分前後のスナップショットがあれば、ヤメ時刻付近から閉店までの差枚変化を比較する。
※これは「ヤメた後にその台がどう動いたか」の実績。ジャグラーは抽選なので、実際に自分が続けた場合と同じ結果になる保証はないよ。

📦 ターキー収集係 v1.5 COPY

GitHub Pagesからの直接取得はP's CUBEのセッション制限でHTMLに差し替わったため、P's CUBE画面上で動く1タップ収集方式に切り替え。
iPhone収集： P's CUBEの台詳細をSafariで開く → 共有 → PEKALOG収集。1台ずつ高速保存し、22台目で全台JSONを返す。
完成JSONは pekalog-turkey-bundle。本日LIVEに加えて「1日前・2日前」の閉店データも同時にLABへ取り込む。
今の運用： 22台収集が終わったら「コピーしてLABを開く」→ 下の「クリップボードから取込」を1回押すだけ。
まだ収集JSONは読み込まれていないよ。

🗃 LABデータ

収集JSON・LABバックアップ・CSV・daily.jsonは全部同じ分析エンジンに入る。

必要データ形式

{
  "snapshots": [
    {"date":"2026-09-22","ts":1790089200000,"machine":"301","model":"gogo3","totalG":7200,"big":38,"reg":34,"diff":2100}
  ]
}

📥 CSV貼り付け取込

自動収集が完成するまでの現実データ入口。
1行目を date,ts,machine,model,totalG,big,reg,diff にして貼れば、そのままLABに追加できる。

🔥 イベント日設定

PEKALOG LABは公開データと自分の仮説を検証する研究ツール。高設定っぽさ・投入推定は統計的な参考値で、設定・勝利を保証するものではありません。
同一GitHub Pagesドメイン配下ならPEKALOGのlocalStorageを直接連携できます。
